# Security Policy

## Supported Versions

The security policy applies to the latest version of the **Periodic-Table** module. As a lightweight, pure HTML/CSS/JS project, we strive to maintain the code in its most secure and optimized form.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

We value the security of our users and the integrity of our educational resources. If you discover a potential security vulnerability, please follow these steps:

1. **Reporting:** Do not report security vulnerabilities via public GitHub issues. Instead, please send an email to the official contact address available at [kajotte-studio.com](https://kajotte-studio.com).
2. **Response:** You can expect an initial response within 48 hours.
3. **Disclosure:** We follow responsible disclosure practices. We ask that you do not share the vulnerability publicly until we have had the chance to address and fix it.

## Philosophy

In line with our commitment to clean code and security, we strictly follow **Content Security Policy (CSP)** principles. This project is designed to be safe, transparent, and easy to audit by the community.
