## 🚀 Project Philosophy
This repository provides optimized **JS** and **CSS** logic for a responsive periodic table. In line with the **Kajotte Studio** philosophy, this project avoids heavy frameworks or CMS overhead, focusing on pure, efficient code.

* **Educational Support:** Created to provide the scientific community with easy access to precise physical data.
* **Minimalism:** Pure HTML/CSS/JS without unnecessary dependencies.
* **Open Standards:** Promoting transparency in digital educational resources.

## 🛠 Usage
As this is a "Pure HTML" project, you can integrate it directly into your web files:

1. Include `style-periodic.css` in your `<head>` section.
2. Include `script-periodic.js` before the closing `</body>` tag.
3. Add the corresponding HTML structure (refer to the project files).
